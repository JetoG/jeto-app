Política de Privacidade

Última atualização: novembro de 2026.

Quais dados o app acessa

Com a sua autorização, o Jeto App lê, somente para leitura, as estatísticas do canal do YouTube da conta que autorizou, por meio da YouTube Data API e da YouTube Analytics API.

Como os dados são usados

Os dados servem apenas para mostrar as estatísticas ao próprio dono do canal. O app não publica, altera nem apaga nada no canal.

Compartilhamento

Os dados não são vendidos, compartilhados nem repassados a terceiros.

Uso das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

Você pode remover o acesso do app a qualquer momento em myaccount.google.com/permissions.
